# Code of Conduct

Ludiary follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies to all project spaces: issues, pull requests and any other place where people act on behalf of the project.

In short: be respectful and constructive, and do not harass anyone.

To report a problem, contact the maintainer through GitHub at [@chamanRMA](https://github.com/chamanRMA). Reports are handled as privately as the platform allows. If a report concerns the maintainer, you can use [GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
